# ไล่ล่าสเกลจักรวาล 🔭

ของเล่นอินเทอร์แอคทีฟสไตล์ [neal.fun](https://neal.fun) — เลื่อนสกอลล์เพื่อซูมออกจาก **ควาร์ก**
อนุภาคเล็กจิ๋วที่สุดเท่าที่มนุษย์รู้จัก ไปจนถึง **เอกภพที่สังเกตได้ทั้งหมด** ทีละก้าว
พร้อมของเทียบขนาดที่คุ้นเคยกว่า 27 จุดตลอดทาง (สเกลรวมกว่า 10⁴⁵ เท่า)

พัฒนาด้วย `React + TypeScript + Vite + Tailwind CSS`

## เริ่มใช้งานในเครื่อง

```
npm install
npm run dev
```

เปิดที่: http://localhost:5174/

## คำสั่งที่ใช้บ่อย

```
npm run dev      # รันเซิร์ฟเวอร์พัฒนา
npm run build    # build เว็บสำหรับ production
npm run preview  # ดูตัวอย่างหลัง build
npm run lint     # ตรวจโค้ดด้วย oxlint
```

## โครงสร้างสำคัญ

- `src/data/scaleData.ts` — ข้อมูลจุดอ้างอิงทั้งหมด (ชื่อ, ขนาดเป็นเมตร, อีโมจิ, ข้อเท็จจริง, สี) แก้ตรงนี้เพื่อเพิ่ม/แก้จุดอ้างอิง
- `src/App.tsx` — กลไกหลัก: อ่านตำแหน่งสกอลล์ → คำนวณสเกลปัจจุบันแบบ log-interpolation ระหว่างจุดอ้างอิงสองจุดที่ใกล้ที่สุด → ไล่สีพื้นหลัง/ครอสเฟดข้อความ
- `src/components/MiniMap.tsx` — แถบจุดด้านขวาสำหรับกระโดดไปยังจุดอ้างอิงใดๆ ได้ทันที (ซ่อนบนจอมือถือ)
- `src/components/Starfield.tsx` — พื้นหลังดาวกะพริบตกแต่ง
- `src/utils.ts` — ฟังก์ชันจัดรูปแบบตัวเลข (เลขยกกำลัง, จำนวนเท่า) และการไล่สี

## กลไกการซูม

ทั้งหน้าใช้ div สูงมาก (`(จำนวนจุด-1) × 100vh`) ครอบ sticky panel ไว้ตรงกลาง
เมื่อผู้ใช้สกอลล์ ตำแหน่งสกอลล์ภายใน track นี้จะถูกแปลงเป็นค่า progress (0–1)
แล้วแมปไปยังตำแหน่งทศนิยมระหว่างจุดอ้างอิง (เช่น 10.4 = อยู่ระหว่างจุดที่ 10 กับ 11)
จากนั้น log-interpolate ค่าขนาดจริง (เมตร) และ lerp สีพื้นหลัง เพื่อให้การไล่สเกลลื่นไหลต่อเนื่อง
ไม่กระตุกเป็นสเต็ปๆ

**ข้อควรระวัง:** ห้ามตั้ง `overflow` (รวมถึง `overflow-x: hidden`) บน `html`/`body`/`#root`
เพราะจะทำให้ `position: sticky` ของ panel หลักพัง (เจอบั๊กนี้ระหว่างพัฒนา)
